# 概率论和数理统计｜个人学习知识库

这是我的浙江大学《概率论和数理统计》（概统 / 概和统）个人学习知识库。课程教师：黄炜。内容覆盖教材第 1–8 章；第 1–5 章为概率论，第 6–8 章为数理统计。

目标是支持平时学习、作业复盘、小测与期末复习，持续记录个人错误、理解和解题模式。这里不是教材摘抄，而是把**标准知识 + 我的理解 + 我的错误 + 典型题型 + 考试识别模式 + 可复用计算流程**积累为长期学习资产。

## 使用方式

1. 学习或复盘时，先搜索 [Cards](Cards/) 中已有的知识对象，优先更新唯一的 canonical Card。
2. 需要新卡时，从 [Templates](Templates/) 选择概念、题目、错误或考试题型模板；按实际来源填写元数据。
3. `Personal Summary｜个人总结` 只记录我真实的理解、错误、类比和思维路径。原理解有错时，保留原话，在标准知识区纠正，并按需建立 Mistake Card。
4. 在 [Learning Log](Progress/Learning_Log.md) 记录学习过程，在 [Roadmap](Progress/Roadmap.md) 更新进度。`Views` 是按复习目的整理的索引，不复制 Card 正文。

ChatGPT 负责教学、答疑、提炼和生成 Codex Handoff；Codex 负责搜索已有 Card、更新/新建/合并文件并维护 metadata；Git 记录版本历史；GitHub 用于远程同步。
