# 习题四 B18：无放回抽样的条件概率与无条件概率

## Problem

B12：袋中有 15 个球，其中 $a$ 个白球，其余黑球；无放回随机抽取 $n$ 次，每次一个，记白球数为 $\xi_n$。已知 $E(\xi_2)=4/3$，求 $a$。

B18：承 B12，当 $n=2$ 时，求 $\operatorname{Var}(\xi_2)$。

本轮重点：**不依赖超几何分布的期望公式，弄清为何第二次抽白球的无条件概率仍是 $a/15$。**

## My First Thought / Mistake

- 我在课上做过类似题，但总觉得“只有第一次抽白球的概率才是 $a/15$，无放回第二次应该变了”。
- 这其实混淆了**已知第一次结果的条件概率**与**没有获知第一次结果的无条件概率**。
- 之前我也质疑是否需要背诵超几何分布的期望公式，更愿意自己推导。
- 本人尚未无提示重做验证，不能标记为掌握。

## Wrong vs Correct｜概率是否附带条件？

设 $A=$ 第一次取白球，$B=$ 第二次取白球。

| 已知的信息 | 概率 | 数值 |
| --- | --- | --- |
| 第一次已经取白球 | $P(B\mid A)$ | $(a-1)/14$ |
| 第一次已经取黑球 | $P(B\mid A^c)$ | $a/14$ |
| 第一次结果未知 | $P(B)$ | $a/15$ |

本人的错误直觉对应第一行，但题目算 $E(X_2)$ 时需要第三行。

### 全概率公式证明

```math
P(B)=P(B\mid A)P(A)+P(B\mid A^c)P(A^c)
```

代入条件概率并化简：

```math
P(B)=\frac{a-1}{14}\cdot\frac{a}{15}+\frac{a}{14}\cdot\frac{15-a}{15}
```

```math
P(B)=\frac{a(a-1)+a(15-a)}{210}=\boxed{\frac{a}{15}}
```

直觉：第一次白球，第二次白球条件概率下降；第一次黑球，则上升。两种可能按概率加权，边际概率仍是 $a/15$。

**无放回不独立，并不等于各次抽取位置的边际概率不同。**

## Correct Solution｜B12：用 0-1 随机变量求期望

定义：

```math
X_i=\mathbf{1}_{\{\text{第 }i\text{ 次抽到白球}\}}
```

$\xi_2=X_1+X_2$。由于不知道此前抽到了什么时，每个位置为白球的概率均为 $a/15$：

```math
E(X_1)=E(X_2)=\frac a{15}.
```

期望线性性质**无需独立性**：

```math
E(\xi_2)=E(X_1)+E(X_2)=\frac{2a}{15}=\frac43.
```

得到：

```math
\boxed{a=10}.
```

### 备选：不使用指示变量

白球数 $\xi_2$ 为 $0,1,2$，概率：

```math
P(\xi_2=k)=\frac{\binom{a}{k}\binom{15-a}{2-k}}{\binom{15}{2}}.
```

所以：

```math
E(\xi_2)=P(\xi_2=1)+2P(\xi_2=2)=\frac{a(15-a)+a(a-1)}{105}=\frac{2a}{15}.
```

## Correct Solution｜B18：用分布律求方差

代入 $a=10$，有 10 白球、5 黑球：

```math
P(\xi_2=k)=\frac{\binom{10}{k}\binom{5}{2-k}}{\binom{15}{2}},
\quad k=0,1,2.
```

| $\xi_2$ | 0 | 1 | 2 |
| --- | --- | --- | --- |
| 概率 | $2/21$ | $10/21$ | $3/7$ |

```math
E(\xi_2^2)=0^2\cdot\frac2{21}+1^2\cdot\frac{10}{21}+2^2\cdot\frac37=\frac{46}{21}
```

因此：

```math
\operatorname{Var}(\xi_2)=E(\xi_2^2)-[E(\xi_2)]^2
```

```math
\operatorname{Var}(\xi_2)=\frac{46}{21}-\left(\frac43\right)^2=\boxed{\frac{26}{63}}
```

无需背超几何分布方差公式。注意方差不能像期望一样在不独立时直接相加，必须考虑协方差；本题用分布律即可。

## Recognition / Transfer

每次看到“第二次抽白球”先问：**“已经知道第一次的结果了吗？”**

- 已知第一次白球 → 条件概率 $(a-1)/14$。
- 已知第一次黑球 → 条件概率 $a/14$。
- 未知第一次结果 → 无条件概率 $a/15$，必要时用全概率公式验证。
- 计数的期望 → 尝试拆成指示变量求和；期望线性性质无需独立。

### 无提示复测

1. 3 白 2 黑，随机无放回抽两次：求第二次白球的无条件概率，以及已知第一次白球时的条件概率。答案：$3/5$，$2/4$。
2. 3 白 2 黑，令 $X_i$ 表示第 $i$ 次白球，求 $E(X_1+X_2)$。答案：$6/5$。
3. 说明为何两次都抽到白球不能简单写成 $(a/15)^2$。

## Personal Summary｜个人总结

- 我老师课上讲过类似题，但我会反复把概率弄错，总觉得“只有第一次的概率才是 $a/15$，第二次不是”。
- 现在需要牢牢记住：**第二次的条件概率可能变化，但未知第一次结果时的无条件概率仍为 $a/15$。**
- 以后看到“第二次”的概率，先写清楚是否已知第一次取球结果；必要时使用全概率公式，而不是直接写出一个剩余球数比例。
- 我想通过 0-1 指示变量和期望线性性质推导本题，而非机械记忆超几何分布的期望公式。
