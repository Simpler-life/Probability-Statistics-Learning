# B3｜点概率与均匀区域混合时的联合分布函数

## Source

用户提供的 B3 题目截图。保留下述原题信息与求解目标。

## Problem｜完整原题

**B3.** 设 $(X,Y)$ 为二维随机变量，已知：

```math
P(X=0,Y=0)=P(X=1,Y=1)=0.1.
```

现知 $(X,Y)$ 落在以下区域：

```math
D=\{(x,y):0\lt x\lt1,\ 0\lt y\lt1\}
```

的任一小区域内的概率与该小区域面积成正比，且 $(X,Y)$ 只能落在点 $(0,0)$、$(1,1)$ 及 $D$ 内，求 $(X,Y)$ 的联合分布函数。

## Tested Knowledge

- 点质量和二维连续分布共同存在时的联合分布函数。
- 用总概率等于 $1$ 求连续部分所占概率与密度。
- 按 $F(x,y)=P(X\le x,Y\le y)$ 截取区域。
- **重点：** 两种容易漏掉的情况，$0.1+0.8x$ 与 $0.1+0.8y$；明确哪一个坐标已覆盖整个 $D$ 方向。
- 边界 $x=0,y=0,x=1,y=1$ 处，点概率是否被包括。

## Recognition｜先拆分三种概率来源

全部可能取值仅在：

1. 点 $(0,0)$：概率 $0.1$；
2. 开单位正方形 $D$：总概率 $1-0.1-0.1=0.8$；
3. 点 $(1,1)$：概率 $0.1$。

单位正方形面积为 $1$，且每个小区域的概率与面积成正比，所以 **$D$ 内的连续部分对应常数密度 $0.8$**。注意不能把点 $(0,0)$、$(1,1)$ 的概率密度也当作 $0.8$；它们是独立的点质量。

## Correct Solution｜完整解答

### 第一步：先确定连续区域的概率

```math
P((X,Y)\in D)=1-0.1-0.1=0.8.
```

因 $D$ 面积是 $1$，对任意 $A\subseteq D$，有

```math
P((X,Y)\in A)=0.8\,S(A).
```

其中 $S(A)$ 是面积。

### 第二步：从联合分布函数定义出发

```math
F(x,y)=P(X\le x,\ Y\le y).
```

这代表从左下方累计到 $(x,y)$ 的概率，由 **$(0,0)$ 点质量 + $D$ 内截取的面积概率 + $(1,1)$ 点质量** 三部分组成。

### 第三步：逐区域讨论（尤其关注两个条带）

**情况 A：$x\lt 0$ 或 $y\lt 0$。**

由于 $X,Y$ 取值均不小于 $0$，任何一个阈值小于 $0$ 都不可能同时满足条件：

```math
F(x,y)=0.
```

**情况 B：$x\ge0,y\ge0$ 且 $x=0$ 或 $y=0$。**

在边界坐标为 $0$ 时，开正方形 $D$ 中没有正面积被截取，但点 $(0,0)$ 已经计入。即

```math
F(x,y)=0.1.
```

**情况 C：$0\lt x\lt 1,\ 0\lt y\lt 1$。**

累计到一个位于 $D$ 内部的 $(x,y)$ 时，已取到 $(0,0)$，再加上面积为 $xy$ 的小矩形；$(1,1)$ 仍未计入：

```math
F(x,y)=0.1+0.8xy.
```

### 情况 D：$0\lt x\lt 1,\ y\ge1$，为什么是 $0.1+0.8x$？

此时 **$y$ 的上界已经达到（或超过）正方形顶部 $1$**，所以 $Y\le y$ 不再限制正方形内的高度，纵向面积已全部覆盖。**但 $x\lt 1$，横向仍只累计宽度 $x$。**

截取区域是宽 $x$、高 $1$ 的竖向条带，面积为

```math
S=x\cdot1=x.
```

包含点 $(0,0)$ 的 $0.1$，但因为 $x\lt 1$，仍**不包含**点 $(1,1)$，所以：

```math
\boxed{F(x,y)=0.1+0.8x,\qquad 0\lt x\lt1,\ y\ge1.}
```

**记忆：$y\ge1$ 时，$y$ 对正方形内的累计已经“饱和”，于是式子只剩 $x$。**

### 情况 E：$x\ge1,\ 0\lt y\lt 1$，为什么是 $0.1+0.8y$？

这次刚好反过来：**$x\ge1$，横向已经覆盖整个正方形宽度 $1$；但 $y\lt 1$，纵向只累计高度 $y$。**

截取的是宽 $1$、高 $y$ 的横向条带，面积为

```math
S=1\cdot y=y.
```

同样包含 $(0,0)$ 的 $0.1$，但 $y\lt 1$，还**没有包含**点 $(1,1)$：

```math
\boxed{F(x,y)=0.1+0.8y,\qquad x\ge1,\ 0\lt y\lt1.}
```

**记忆：$x\ge1$ 时，$x$ 方向已“饱和”，于是式子只剩 $y$。**

### 情况 F：$x\ge1,\ y\ge1$。

点 $(0,0)$、全部区域 $D$、点 $(1,1)$ 均被计入：

```math
F(x,y)=0.1+0.8+0.1=1.
```

### 第四步：汇总完整分段答案

```math
\boxed{
F(x,y)=
\begin{cases}
0, & x\lt0\ \text{或}\ y\lt0,\\[2pt]
0.1, & x,y\ge0,\ \text{且 }(x=0\text{ 或 }y=0),\\[2pt]
0.1+0.8xy, & 0\lt x\lt1,\ 0\lt y\lt1,\\[2pt]
0.1+0.8x, & 0\lt x\lt1,\ y\ge1,\\[2pt]
0.1+0.8y, & x\ge1,\ 0\lt y\lt1,\\[2pt]
1, & x\ge1,\ y\ge1.
\end{cases}
}
```

注意边界 $x=1$ 或 $y=1$ 时也必须判断 $(1,1)$ 是否同时被计入。只有 **$x\ge1$ 且 $y\ge1$** 才计入额外的 $0.1$。

## 快速核对｜三种非零面积情况

| 条件范围 | 截得的 $D$ 内矩形 | 面积 | 累计分布函数 |
| --- | --- | --- | --- |
| $0\lt x\lt 1,\ 0\lt y\lt 1$ | 宽 $x$、高 $y$ | $xy$ | $0.1+0.8xy$ |
| **$0\lt x\lt 1,\ y\ge1$** | **宽 $x$、高 $1$** | **$x$** | **$0.1+0.8x$** |
| **$x\ge1,\ 0\lt y\lt 1$** | **宽 $1$、高 $y$** | **$y$** | **$0.1+0.8y$** |

特别警惕：**固定在范围之外（达到 1）的那个变量反而从面积表达式中消失。**
- $y\ge1$，高度取完整的 $1$，留下 $x$；
- $x\ge1$，宽度取完整的 $1$，留下 $y$。

## 更紧凑的通式｜避免漏掉边界

令截断函数

```math
g(t)=
\begin{cases}
0,&t\le0,\\
t,&0\lt t\lt1,\\
1,&t\ge1.
\end{cases}
```

则

```math
F(x,y)=
0.1\,\mathbf1_{\{x\ge0,\ y\ge0\}}
+0.8\,g(x)g(y)
+0.1\,\mathbf1_{\{x\ge1,\ y\ge1\}}.
```

$\mathbf1$ 表示示性函数，括号中的条件成立时为 $1$，否则为 $0$。这个表达式与分段答案等价，可以帮助检查是否漏掉 $(0,0)$ 与 $(1,1)$ 的点质量。

## Mistake｜本题最常见的错误

- 只写 $0.1+0.8xy$，忽略 $x$ 或 $y$ 超过 $1$ 后截取面积不能继续增大。
- **把 $0.1+0.8x$、$0.1+0.8y$ 写反。**
- 错以为 $x=1$ 或 $y=1$ 中任一成立，就已经计入点 $(1,1)$ 的 $0.1$；实际上需要两个条件同时成立。
- 因点边界“面积为零”就忽略 $(0,0)$ 的概率 $0.1$：离散点质量不能由面积是否为零判断。
- 错把整个混合分布当成一个普通二维连续型分布，导致遗漏两个原子点。

## Calculation Skeleton｜考试作答框架

1. 先列全部概率来源：点 $(0,0)$ 占 $0.1$，开方形 $D$ 占 $0.8$，点 $(1,1)$ 占 $0.1$。
2. 写定义 $F(x,y)=P(X\le x,Y\le y)$。
3. 判断两点是否落入累计矩形：$x,y$ 都不小于 $0$ 才计入 $(0,0)$；都不小于 $1$ 才计入 $(1,1)$。
4. 连续部分的累计面积等于被截取的宽度乘高度，并且每个方向最多只能取到 $1$。
5. **单边饱和时千万不要漏：$y\ge1$ 产生 $0.8x$，$x\ge1$ 产生 $0.8y$。**
6. 汇总分段式，检查覆盖所有边界、彼此不重叠且 $F(+\infty,+\infty)=1$。
