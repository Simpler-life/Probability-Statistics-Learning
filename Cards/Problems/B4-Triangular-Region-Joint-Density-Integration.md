# B4｜三角形区域上的密度归一化与概率积分

## Source

用户提供的 B4 题目截图，完整誊写原题和三个小问。以下补充解答与可复用积分方法。

## Problem｜完整原题

**B4.** 设二维随机变量 $(X,Y)$ 的联合密度函数为

```math
f(x,y)=
\begin{cases}
c(y-x), & 0\lt x\lt y\lt1,\\
0, & \text{其他}.
\end{cases}
```

（1）求常数 $c$；

（2）求 $P(X+Y\le1)$；

（3）求 $P(X\lt0.5)$。

## Tested Knowledge

- 由二维概率密度归一化求未知常数。
- 将原始支持区域 $0<x<y<1$ 表示成可积分的不等式。
- 将事件 $X+Y\le1$ 与原始支持区域取交集。
- 通过边界线交点确定外层积分上下限。
- 比较先积 $y$ 与先积 $x$ 的不同，识别何时需分段。

## Recognition｜先辨认原始区域

支持区域 $D$：

```math
D=\{(x,y):0\lt x\lt y\lt1\}.
```

该区域是 $x=0$、$y=x$、$y=1$ 所围三角形内部。固定 $x$ 时，$x<y<1$，且 $0<x<1$，因此便于采用先 $dy$ 后 $dx$ 的积分顺序：

```math
\iint_D f(x,y)\,dx\,dy
=\int_0^1\int_x^1 f(x,y)\,dy\,dx.
```

## Correct Solution｜完整推导

### （1）利用密度归一化求 $c$

密度在全平面积分为 $1$，且在 $D$ 外为零：

```math
\begin{aligned}
1
&=\int_0^1\int_x^1 c(y-x)\,dy\,dx\\
&=c\int_0^1\left[\frac{(y-x)^2}{2}\right]_{y=x}^{y=1}\,dx\\
&=\frac c2\int_0^1(1-x)^2\,dx\\
&=\frac c2\cdot\frac13
=\frac c6.
\end{aligned}
```

因此：

```math
\boxed{c=6}.
```

因为 $y>x$，密度非负性也得到保证。

### （2）求 $P(X+Y\le1)$

新增事件等价于 $y\le1-x$。同时保留原始条件 $y>x$，对固定 $x$，必须有

```math
x<y\le1-x.
```

为了让上述区间非空，需要 $x<1-x$，即 $x<1/2$。因此整个目标区域可表示为

```math
0\lt x\lt\frac12,\qquad x\lt y\le1-x.
```

直线 $y=x$ 与 $y=1-x$ 的交点为 $(1/2,1/2)$；积分次序先 $dy$ 后 $dx$ 不需要再次分段：

```math
\begin{aligned}
P(X+Y\le1)
&=\int_0^{1/2}\int_x^{1-x}6(y-x)\,dy\,dx\\
&=3\int_0^{1/2}(1-2x)^2\,dx\\
&=3\left[x-2x^2+\frac43x^3\right]_0^{1/2}\\
&=\boxed{\frac12}.
\end{aligned}
```

**积分限形成过程：** 原本 $y$ 上限为 $1$；加入 $x+y\le1$ 后，上限收紧为 $1-x$。要求下限 $x$ 不高于上限 $1-x$，自然推出外层 $x$ 范围只到 $1/2$。

### （3）求 $P(X<0.5)$

事件只新增 $x<1/2$，而原来的 $x<y<1$ 不变，因此：

```math
\begin{aligned}
P(X\lt0.5)
&=\int_0^{1/2}\int_x^1 6(y-x)\,dy\,dx\\
&=3\int_0^{1/2}(1-x)^2\,dx\\
&=\left[-(1-x)^3\right]_0^{1/2}\\
&=1-\frac18\\
&=\boxed{\frac78}.
\end{aligned}
```

## Key Insight｜积分区域等于两个条件的交集

**先列原始支持区域，再将题目中的事件转换成不等式，最后求交集。**

| 所求 | 支持区域附加条件 | 推荐积分限 |
| --- | --- | --- |
| 归一化 $c$ | 无 | $0<x<1,\ x<y<1$ |
| $P(X+Y\le1)$ | $y\le1-x$ | $0<x<1/2,\ x<y<1-x$ |
| $P(X<1/2)$ | $x<1/2$ | $0<x<1/2,\ x<y<1$ |

**第二问的外层上界不是凭记忆设为 $1/2$，而是由两条边界 $y=x$ 与 $y=1-x$ 的交点推导出来。**

### 改换积分次序为什么可能要分段？

同一第二问，若先对 $x$ 积分后对 $y$ 积分，需同时满足

```math
0\lt x\lt y,\qquad x\le1-y.
```

此时上界是 $\min(y,1-y)$；当 $y=1/2$ 时，上界从 $y$ 切换成 $1-y$：

```math
\begin{aligned}
P(X+Y\le1)
={}&\int_0^{1/2}\int_0^y6(y-x)\,dx\,dy\\
&+\int_{1/2}^1\int_0^{1-y}6(y-x)\,dx\,dy.
\end{aligned}
```

因此，**选择积分次序的技巧：尽量选择能用一组连续上下限描述整个区域的顺序，减少分段。**

## Calculation Skeleton｜考试通法

1. 写出联合密度非零区域 $D$ 并画出边界。
2. 求 $c$ 时在整个 $D$ 上积分，并令总概率为 $1$。
3. 求事件概率时写 $D\cap E$，其中 $E$ 是所求事件不等式对应的区域。
4. 固定外层变量，确定内层变量上下限，再反推外层变量可行范围。
5. 在复杂情况下比较两种积分次序，选择较少分段的那个。
6. 校验概率在 $[0,1]$ 内，且联合密度非负。

## Mistake｜易混点

- 只使用事件 $X+Y\le1$，忘记联合密度在 $y\le x$ 等区域为零。
- 第二问仍把内层上限写为 $1$，忽略新增边界 $y=1-x$。
- 第二问沿用外层上限 $1$，忽略 $x<1-x$ 导致只有 $x<1/2$ 才存在目标区域。
- 误以为换积分次序时仍可无条件使用同一组积分限。
- 混淆 $P(X<0.5)$ 与 $P(X+Y\le1)$ 的两种附加约束。
